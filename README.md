# Sellam Store — Backend

API REST Spring Boot pour la gestion de boutique (auth, produits, ventes, stock, bilan journalier).

## Stack
- Java 26, Spring Boot 4.0.7
- PostgreSQL
- JWT pour l'authentification

## Lancer le projet
1. Configurer `application.properties` avec ta base PostgreSQL locale
2. `mvn spring-boot:run`
3. API disponible sur `http://localhost:8080`
